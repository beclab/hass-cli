# Suite map

Read when two skills seem to own a request. Back to [the front door](../SKILL.md). Turning one existing device on or off never needs this: [the front door's control](../SKILL.md#control-a-device) covers it.

| Sensors, numbers, selects, vacuums, alarm panels, to-do lists, calendars | [`ha-entities`](../../ha-entities/SKILL.md) |
| What state something is in now, or was in earlier today | [`ha-states`](../../ha-states/SKILL.md) |
| Any other service, or what fields a service takes | [`ha-services`](../../ha-services/SKILL.md) |
| Who is home, zones, device trackers | [`ha-presence`](../../ha-presence/SKILL.md) |
